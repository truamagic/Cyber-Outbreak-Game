# CYBER OUTBREAK v0.6

架空の病院情報システムを扱うターン制ストラテジーゲーム。教育・娯楽用フィクションであり、実際の侵入手順、患者情報、外部通信は含みません。

## v0.6 — 初心者チュートリアル

- タイトル画面の **「初心者向けチュートリアル」** で開始できます。既存の通常ゲームはそのまま利用可能です。
- 9つのガイド付き操作：開始ノード選択 → 模擬データ回収 → 事務情報ノード選択 → 進出 → 進化研究所 → 解析Lv.1購入 → 戦術ショップ → 追加行動力購入 → ターン終了。
- 指定の操作対象を強調表示し、別の行動は一時的に制限します。誤操作で行動力やIPを失わない設計です。
- 練習専用の65 IPで開始し、初回の進出は成功確定。通常ゲームの確率やポイントは変更しません。
- いつでも「チュートリアル終了」を選べます。チュートリアル完了後は同じゲームをそのまま続けられます。
- 右側スライドパネル、PC、スマホ横画面に対応。画面縦向きの案内も維持します。

## v0.5 — スマートフォン横画面UI
- スマホ横向き（高さ600px以下・横幅1100px以下のタッチ環境）では、**左にネットワークマップ、右に操作パネル**を並べた画面になります。メイン画面は縦スクロールせず、右パネル内で詳細をスクロールします。
- 右側は「ノード」「戦況」「ログ」「実績」のタブで表示を切り替えられます。マップ上のノードをタップすると「ノード」に戻ります。
- 「マップ拡大」では右側を隠してネットワークを広く表示でき、「操作を表示」で復帰します。ショップ・進化研究所は従来どおりスライドパネルです。
- **スマホ縦向き**では「スマートフォンを横画面にしてください」と案内を表示します。「縦画面のまま続ける」で従来の縦レイアウトを使用できます。端末を横に回転すると案内は自動的に消えます。
- 回転を強制する機能や端末の画面ロックを解除する機能はありません。回転ロックを解除して横向きにしてください。
- 新規ファイル：`css/mobile.css`（横・縦レイアウト）と `js/layout.js`（画面切替・案内表示）。

## v0.4
- HOSPITAL DEFENSE 風の右スライドパネルを導入。ショップと進化研究所は地図の上に重なって開き、Esc・背景クリック・閉じるボタンに対応。
- 戦術ショップでは選択ノードに対して「継続収入ユニット（16 IP/1 AP）」「要求イベント（1 AP）」を実行。「追加行動力（24 IP、各ターン1回、+1 AP）」を追加。
- 進化の4分野（拡張・解析・適応・継続）を最大 Lv.3 まで強化可能。連続購入可。
- HTML / CSS / JS を分割。既存のネットワーク分離、防御・復旧、12種の実績、難易度を維持。

## 実行方法
同一フォルダ構造のまま `index.html` をブラウザで開いてください。外部ライブラリ・ビルド・サーバーは不要。GitHub Pages など静的ホスティングでも配信可能です。**単一HTMLのみをコピーしても動作しません。**

マップでノードを選択し、模擬データの回収や進出を行います。情報ポイント（IP）はショップ・進化に消費します。病院側はネットワーク分離・防御強化・復旧で対抗します。規定ターンまたは警戒度100に到達する前に、累計IPと接続ノード数の目標を達成してください。

実績のみブラウザのローカルストレージに保存されます。ゲーム途中の進行は自動保存されません。ゲーム内の数値や対策効果は現実のセキュリティ評価には利用できません。
