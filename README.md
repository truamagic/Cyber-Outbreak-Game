# CYBER OUTBREAK v0.7.1

架空の医療情報システムを舞台とする、情報セキュリティの防御と対応を考えるターン制ゲームです。病院の構造・データはすべて**架空**で、実際の侵入、認証情報の悪用、情報取得、個人情報の送信は行いません。

## v0.7.1 — 仮アイコン採用

- 仮作成したCYBER OUTBREAKのロゴをブラウザ用アイコンとして採用。ルートの `favicon.ico` を参照します。
- ゲーム画面左上のブランドマークも同じアイコンに変更しました。
- Web配信用の軽量版として、提供された7サイズICOのうち16px・32pxの画像を抜き出して再構成しています（オリジナルの図柄は変更していません）。

## v0.7 の新要素

### IP と RP：2種類の育成リソース
- **IP（戦術ポイント）**：模擬データ回収、継続収入、要求イベント、好機イベントで獲得。その攻略内のショップと進化で使い、次の攻略へ引き継ぎません。
- **RP（研究ポイント）**：新規アチーブメント（初回のみ +5 RP）、攻略結果（条件を満たした成功 +15 RP／失敗 +3 RP）、初回病院タイプクリア（+10 RP）、高い管理水準の病院に対するクリアボーナス（A +8、B +4、C +2、D +0）で獲得します。攻略結果によるRPは**3ターン以上かつ模擬データ回収12 IP以上**で獲得可能です。チュートリアルから開始した攻略は、途中で通常操作に切り替えてもRP・新規実績報酬の対象外です。RPを獲得したい場合は通常ゲームから開始してください。
- **永久研究所**：初期IP +5/Lv、開始ターンのAP +1、好機の持続期間 +1ターン/Lv、開始警戒度 -2/Lv。いずれも**次の攻略開始時から適用**されます。
- RP・研究レベル・初クリア状況・対象となった攻略回数をブラウザのローカルストレージに保存します。JSONファイルで研究データのバックアップと復元が可能です。異なる端末に自動同期されません。JSONの読み込みは現在の研究データを置き換えます。

### 病院の管理水準
難易度とは独立して、架空の病院タイプ A（高度管理）／B（標準管理）／C（改善途上）／D（管理不十分）を選択します。
病院ごとに **システム保守、職員教育、アクセス管理、監視・検知、復旧体制** の5領域に水準が設定され、攻略開始時に小幅な変動があります。病院側はターン進行に伴い対策を改善することがあります。現実の施設評価ではありません。

### 突然の好機
ゲーム内抽選で、期間限定の好機イベントが発生します。管理成熟度が低い病院ほど好機の発生率が高まります（概ねA 11％前後、D 47％前後／ターンで、毎回変動）。Aでも発生率はゼロではありません。
イベントの例：保守計画の遅れ、架空の認証情報のメモ紛失、職員教育の空白、監視の空白、復旧手順の遅れ。
「好機を活用する」（1 AP、成功時IP獲得・警戒度上昇）／「見送る」を選択できます。病院側が点検・封じ込めすると期間途中でも消えることがあります。**現実の利用方法や侵入手順は再現しません。**

### 病院影響指数 HI
IP/RPと別に、模擬的な影響を表示します。
- 情報面 35％、システム停止 30％、経済面 15％、診療継続への影響 20％の重みで、0〜100の **HI** を算出。
- 診療継続率を別に表示。患者の負傷・直接的な被害を得点獲得条件にしません。
- 仮想損失額は「経済影響のゲーム値 × 20万円」で算出。実在の損害・個人情報の価値・医療安全上のリスクの推計ではありません。
- 復旧によって一部の業務影響が減少しますが、既に取得した仮想データの影響は取り消しません。

## 操作
1. 最初に難易度と病院A〜Dを選択して開始します。初めての人は **初心者向けチュートリアル** も利用できます。
2. マップでノードを選択して進出・回収、ショップで戦術を購入し、進化ツリーでその攻略の能力を強化します。
3. ターンごとに病院側がネットワーク分離、防御強化、復旧を実施します。好機イベントが出たら「好機」タブで選択します。
4. 所定のIPと有効ノード目標を満たすとクリア。結果画面に獲得RP・HI・診療継続率を表示します。
5. 「永続研究」でRPを使い、次の攻略に向けて恒久強化できます。

```text
index.html
favicon.ico          提供アイコンをもとにしたブラウザ用ファビコン
css/styles.css       基本デザイン

css/tutorial.css     初心者チュートリアル
css/progression.css  成熟度・好機・HIの画面
js/game-data.js      架空マップ・難易度・実績
js/progression.js    病院A〜D、永続研究、HI・好機モデル
js/app.js            ゲーム本体とUI描画
js/layout.js         スマホ横画面の切替
js/tutorial.js       チュートリアル進行
tests/progression.test.cjs  純粋計算・セーブ機構のテスト
README.md
CHANGELOG.md
```

ファイル構造を保ったまま `index.html` を開くか、GitHub Pages などの静的ホスティングに配置してください。外部ライブラリ・ビルド・サーバー不要、ゲームからのネットワーク通信なし。ブラウザのストレージを消去すると、JSONに書き出していないRP・研究レベル・実績は失われる場合があります。
