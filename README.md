# CYBER OUTBREAK v0.3

架空の病院情報システムを題材にした、単一HTMLで動くターン制ストラテジーゲームです。

> **教育・娯楽用のフィクションです。** 実際の医療機関の構成、攻撃手順、患者情報、外部通信は含みません。ゲーム上の効果・ポイントは架空のルールであり、現実のセキュリティ評価に利用できません。

## v0.3：画面デザインの刷新

ゲームのルールとオフライン動作を維持し、プレイ画面を「タクティカル・コマンドコンソール」風に再設計しました。

- **戦況ダッシュボード**：所持IP、累計獲得IP、接続中のノード数、ターン・行動力をひと目で把握できます。
- **警戒度ダイヤル**：病院側の警戒度を円形ゲージと状態ラベルで可視化。
- **ネットワークの演出**：接続状態・選択中・遮断・継続収入などを色とアイコンで区別。アニメーションを抑える環境設定にも対応。
- **ノード操作パネル**：選択したシステムの状態・防御強度・模擬データ残量・操作を再整理。
- **進化ツリー**：レベルゲージを追加し、強化状況を確認しやすくしました。
- **実績コレクション**：「すべて」「獲得済み」「未発見」の表示切替と達成率バーを追加。
- **イベント表示**：最新イベントをヘッダー付近に表示。状況変化を通知で確認できます。
- **スマホ対応**：縦長レイアウトに最適化し、マップの横スクロールと「全体表示」の切替に対応。

## 操作画面について

画面上部の「ネットワーク」「ノード操作」「進化」「実績」「通信ログ」はページ内の該当セクションへ移動します。マップの各ノードはクリック・タップまたはキーボードの Enter キーで選択できます。

## 遊び方

1. `index.html` をダウンロードして、PCまたはスマートフォンのブラウザで開きます。
2. 難易度を選び、「ゲーム開始」を押します。
3. ノードを押して模擬データを回収し、接続された別のノードへ影響を広げます（基本は毎ターン3行動）。
4. 獲得した情報ポイント（IP）で進化ツリーを強化します。
5. 病院側はネットワーク分離、防御強化、復旧などの対応を行います。接続が遮断されると、影響範囲や継続収入が一時的に制限されます。
6. 制限ターンと警戒レベルに注意しながら、累計IPと接続ノード数の目標を達成してください。

## v0.2 から継続しているゲーム機能

- **動的なネットワーク分離**：病院側が接続を一時遮断し、再接続イベントも発生します。
- **継続収入**：一部の架空サーバーノードにユニットを配置すると毎ターンIPを得られます。分断中は停止し、復旧によって撤去される場合があります。
- **要求イベント**：模擬データを一定量回収したノードで、架空の要求イベントを1回選択できます。結果は確率判定で、警戒度が上昇します。
- **実績・隠し記録**：12種類のアチーブメント・架空資料を収集できます。獲得実績のみブラウザ内のローカルストレージに保存されます。
- **進化ツリー**：拡張・解析・適応に加え、継続収入の強化を追加しています。
- **難易度**：カジュアル、スタンダード、チャレンジの3種類。

## 技術構成

HTML / CSS / JavaScript のみ。ビルド不要、外部ライブラリ不要、サーバー不要。ゲーム本体は `index.html` だけで動作します。

ネットワーク通信や実際のシステムへのアクセスは実装していません。プレイ途中のゲーム状態は自動保存されません。実績の保存はブラウザ設定（ローカルストレージの利用可否）に依存します。

PC幅（1365px）とスマートフォン幅（390px）のChromiumで、開始・ノード操作・継続収入・ネットワーク分離・実績表示・ターン進行を確認しています。難易度ごとに自動プレイを実行し、ゲーム進行と終了条件を確認しました。
