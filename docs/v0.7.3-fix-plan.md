# CYBER OUTBREAK v0.7.3 修正計画・受入基準

作成日: 2026-11-08 JST
対象基準: v0.7.2 / commit `1cbebf285590d15141deb42a0c71c9b04af8bf71`
参照: ミーナ（Dots）中間デバッグ、Grokbot＋リツの91本プレイ・検証の更新報告

## 方針
本バージョンは**保存信頼性と操作UIの安定化**に限定する。
設定値（難易度、管理成熟度、好機確率、ポイント価格）は変更しない。
91本のボット成績を人間の初見難易度の代替にしない。

## データ互換性
- localStorage の既存キー `cyber-outbreak:meta:v07` は変更しない。
- schema 1を読み込み、schema 2へ変換する。研究レベル、RP、初回クリア、攻略回数を維持。
- schema 2は `claimedRewards` と `ledgerReady` を追加。既存の**表示中の実績**を移行時に報酬済みとして登録。
- **制約**: 更新前に実績リセットして消えた旧報酬IDは復元できないため、その分の再付与抑止は保証できない。更新前のJSONバックアップを推奨。
- レガシーJSON（schema 1）もインポート可能にする。セーブが拒否されたときは警告を表示。

## 検証
- `node tests/progression.test.cjs`（既存の純粋計算・保存テスト）
- `node tests/stability.test.cjs`（本体end/earnの模擬統合テスト）
- スマホ横・縦／キーボード操作の実ブラウザ確認が別途必要。
- Playwrightによる91本の再実行、人による初心者テスト、実機Safari/Firefoxは今回の完了判定の対象外。

## 修正範囲外
- 好機の成功確率、管理水準の重み、戦略A/B/Cのバランスの数値
- 新しい攻撃シナリオ、永続研究・実績の新規追加
- 現実のシステムに対する侵入手順・患者データの利用

## 完了の区別
**コード修正済み**、**自動テスト通過**、**実ブラウザ実測確認済み**は別々に報告する。
